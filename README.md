# WebNetProbe 内网流量探针平台

纯 Python 标准库实现的轻量级内网流量监控与安全管理平台，**零第三方依赖**，克隆即可运行。

> 当前版本：v2.21.15 ｜ 本包为**无数据库分发版**：不携带任何数据库/密钥/日志文件，首次启动自动初始化。

---

## ✨ 功能特性

| 模块 | 能力 |
|---|---|
| 内网资产 | 设备 MAC 注册表（ARP 采集 + IEEE OUI 40,265 条厂商识别）、在线状态排序 |
| 实时会话 | 协议/本地地址/远端地址/状态/PID 筛选排序、软件自动识别（浏览器/飞书等树形流量分析） |
| 流控策略 | 基于 MAC/IP/端口/协议的精细策略，上下行限速、动态流控、端口封禁（高亮+手工） |
| 安全防护 | 攻击告警、态势感知（攻击检测/白名单/域名分析/高亮提示）、IP 查询/计算器、DDoS 检测 |
| 网络工具 | 长期 Ping（自动本地保存+CSV 导出）、多目标网络抖动实时监测、路由追踪、网速测试（Speedtest 嵌入） |
| 数据回溯 | 历史带宽统计（日/月/年累计、每日 0 点重置）、秒级时间段选择、峰值分析 |
| 平台接入 | 微步云沙箱 / 威胁情报 / 蜜罐（s.threatbook.com / x.threatbook.com / hfish.net）一键跳转 |
| 合规审计 | ISO27001 / 等保 3.0 合规体检表（CSV/JSON/PDF 导出）、数据真实性校验 |
| 账户体系 | 登录账户分级（admin 最高权限 + 细粒度权限分发）、密码策略（≥8 位 4 选 3、90 天改密）、撞库审计（5 次锁定 30 分钟 / 3 轮永久停用） |
| 审计追踪 | 全操作审计留痕（登录/查看/修改/导航/点击）、毫秒级实时刷新、时间段导出 |
| 运维管理 | 一键恢复出厂、备份/回滚（用户选择版本）、DB 滚动（≥1GB 或 ≥1 年自动切库）、通知接口（邮箱/企业微信/微信/飞书） |

## 🚀 快速开始

### 环境要求

- **Python 3.8+**（纯标准库，无需 pip install）

### Windows

```bat
启动.bat
```

或手动：

```bat
python server.py
```

### Linux / macOS

```bash
bash start.sh
# 或
python3 server.py
```

启动后访问：**http://127.0.0.1:8090**

**默认账号：`admin` ／ 密码：`Admin@123456`**（首次登录请立即修改密码）


## 📦 数据说明（无数据库分发）

- 本包**不包含**运行数据库 `data/webnetprobe.db`、密钥 `auth_master.key`、会话/审计/历史数据等。
- 首次启动自动创建 `data/` 目录与 SQLite 数据库，业务数据（设备/会话/审计/策略/流量）均持久化于本地。
- 数据备份与回滚：

```bash
python backup_db.py      # 在线备份（不自动删除，可 rollback.py clean 清理）
python rollback.py       # 列出镜像 → 交互选择回滚版本
```

- 一键恢复出厂：

```bash
python manage.py reset   # 自动备份当前库 → 重建 admin/Admin@123456 → 重启服务
```

- DB 滚动：数据库 ≥1GB 或使用 ≥1 年自动切换新库（旧库归档保留）。

## 🔐 安全说明

- 默认账号密码请**首次登录后立即修改**（密码策略：≥8 位，大写/小写/数字/特殊字符 4 选 3）。
- 服务监听 `0.0.0.0:8090`，生产环境建议仅限本机/内网访问，或置于防火墙之后。
- 审计日志记录全部登录/操作/导航留痕；连续登录失败自动锁定与停用。
- 本软件仅用于**内网授权范围**内的流量监控与安全运维，请遵守所在组织的安全合规要求。
