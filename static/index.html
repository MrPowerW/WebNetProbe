ℹ️ 使用说明
1. 导出文件为实时生成；选择时间段后精确到秒过滤会话与告警数据（资产/设备清单为全量快照）
2. CSV文件使用UTF-8 BOM编码，直接用Excel打开不会乱码
3. 探针重启后内存历史数据会清空，如需长期保存请定期导出
4. 点击浏览器地址栏访问 http://[本机IP]:8090 即可在局域网内任意设备访问本平台
💡 模块重置与导出均实时生效；重置后全系统页面通过事件总线动态同步刷新。
🚦 精细流控策略
策略模型：目标（设备 / MAC / IP / IP段 / 分组）× 匹配（端口 / 协议 / 时段）× 动作（上下行限速 / 优先级 / 动态）。 平台按策略仿真评估每台设备生效限速，并基于会话估算检测超限告警（估算值，非真实抓包）。 如需真实限速，点击"导出限速脚本"部署到 Linux 网关 / OpenWrt 路由器（当前为策略管理路线，真实执行由执行层适配器承接）。
